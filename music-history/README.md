# 音楽家と録音の時代地図

音楽家の生涯・代表作の成立や初演・世界史・録音技術を重ねた、インタラクティブな音楽史年表です。

- **公開用ファイル**: [index.html](./index.html)（CSS・JavaScript・年表データをすべて内包する単一HTML）
- **収録**: 音楽家69人、代表作品70件、歴史・録音技術・録音史の節目29件
- **機能**: 人物の分類別フィルター、日本語/欧文名検索、録音有無の絞り込み、ズームと年代ジャンプ、詳細ダイアログ
- **主題**: 1889年のブラームス蝋管録音、1903年のヨアヒムの演奏、1911/1913年の初期交響曲録音、1928年のクライスラーとラフマニノフの共演

[GitHub Pages](https://docs.github.com/en/pages) を有効にするとブラウザで直接閲覧できます。単独HTMLなので `index.html` を保存して開く方法でも動きます。

## 典拠

参照文献と出典へのリンクはページ内に収録しています。主要資料は以下の通りです。

- [米国議会図書館：録音技術史年表](https://www.loc.gov/programs/national-recording-preservation-plan/tools-and-resources/historical-background/timeline/)
- [米国国立公園局：ブラームスの1889年蝋管録音](https://home.nps.gov/edis/learn/photosmultimedia/theo-wangemann-1889-1890-european-recordings.htm)
- [Joseph Joachim Research：1903年の演奏録音](https://josephjoachim.com/2026/01/22/about-joachims-recordings/)
- [Naxos Historical：クライスラー × ラフマニノフの1928年録音](https://www.naxos.com/catalogue/item.asp?item_code=8.110968)
- [JAMS：1911～1913年の交響曲全曲録音](https://doi.org/10.1525/jams.2023.76.1.113)

録音とピアノロールは区別しています。存命の音楽家の表示上の終期は2026年です。作品の年は原則として「作曲／完成／初演／出版」のいずれかを表示し、網羅性を意図しません。

※独立した編集用プロジェクトには `data.json` と `make_data.py` も含めています。GitHub上のこのフォルダは配布しやすさのため単一HTMLにしています。
